# Zambo skills

Agent skills for Zambo, the verifiable work layer for AI: 153 tools behind one MCP endpoint at https://zambo.dev/mcp, cross-AI continuity (HANDOVER), and a verifiable AER-1 receipt for every job.

- `skills/zambo/` — connect to Zambo and run real work with receipts.
- `skills/zambo-receipts/` — verify an AER-1 receipt and contest a "done" claim.
- `skills/verify-before-done/` — the completion contract: re-fetch reality, recompute the digest, attach the receipt, then claim done.

Install with the skills CLI: `npx skills add zambodotdev/zambo-skills`
